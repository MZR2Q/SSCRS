# Walkthrough videos

Rendered walkthroughs of the ten proposed visual directions. Each video is
generated frame by frame (60 fps, 1440x900, H.264 CRF 15) from a
time-driven demo page via a synthetic cursor that scrolls, hovers, opens an
FAQ question and selects a document — not a screen recording. Sources:
`docs/proposals/pages2/` (`tour15.html?t=A..E`, `tour7/8/9/10.html`,
`demo6.html`) driven by `engine.js` / `record.js`.
