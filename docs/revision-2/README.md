# Revision 2 — the board kept the current design

The board chose the **current site** over the ten proposed directions, with
four requests. `docs/SSCRS-Current-Design-Revisions.pdf` is the deck sent back.

| # | Request | Status |
|---|---|---|
| 1 | Green disc behind the hero seal (from direction 3) | **Applied** — `.hero-seal-plate` in `pages/index.html` / `styles.css` |
| 2 | Chairperson card as in direction 3 | **Applied** — `.member-feature` now uses `--green-900` |
| 3 | Navbar is small and unclear, font is weak | **10 proposals** — awaiting a number |
| 4 | Dark navy boxes are too dark; want green and simpler | **5 treatments** — awaiting a number |

## Files

- `navbars.html` — all ten navbars in one page. `?v=1..10&s=default|hover|open&l=en|ar`.
  It expects `seal.png` and `backdrop.png` beside it (see `tools/navshots.js`).
- `box-options/opt1..5.css` — each is a plain override layer on top of
  `styles.css`. To apply the chosen one, append its rules to `styles.css`
  (then drop the `!important`s where the source rule can be edited instead).
  Generated by `tools/gen_boxcss.py`.
- `tools/` — screenshot scripts (Playwright, need the site on
  `localhost:8765`) and `build_pdf.py` + `pdf.js`, which assemble the deck.

## Applying the choices

- **Navbar N** — port the `[data-v="N"]` rules from `navbars.html` into
  `partials/header.html` + the header block of `styles.css`, keep the existing
  `data-nav-*` hooks and the mobile sheet, then `python build.py`.
- **Box treatment N** — merge `box-options/optN.css` into `styles.css`, bump
  `VERSION` in `build.py`, rebuild.
